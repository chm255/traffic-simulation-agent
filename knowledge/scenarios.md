## Current Agent Capability Limits

The current Traffic Simulation Agent does not have a real controller-selection tool.

Therefore, the Agent must not claim that it changed or selected a traffic controller unless such a capability is explicitly implemented later.

The current Traffic Simulation Agent does not have a real demand-modification tool.

Therefore, the Agent must not claim that it modified traffic demand unless such a capability is explicitly implemented later.
